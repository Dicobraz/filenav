# Urfin

<img src="assets/icon/urfin-256.png" width="96" alt="Иконка Urfin">

Быстрый двухпанельный файловый менеджер: функции и раскладка DN/Far, визуальный язык Windows Fluent.
Rust, UI на GPUI (gpui-kit, [ADR-0018](docs/adr/0018-ui-gpui.md)). Только Windows 10/11 (S0-decisions №57).

**Статус (2026-10-23):** M0–M2 готовы, идёт M3 (терминал и командная строка). Готовой к выпуску сборки ещё нет — сборки для ручной приёмки владельцем.

## Что уже есть

- **Панели.** Две панели с табами, режимы Brief / Medium / Full / Wide, дерево, «Сведения», быстрый просмотр; путь с переходом по сегментам; сортировка, фильтр, скрытые файлы; закладки и история; автообновление по изменениям ФС; размер папок; быстрый поиск (Alt+буква).
- **Клавиатура.** Пресеты Far и DN, свой keymap, хоткеи с буквой — на любой раскладке ([docs/keys.md](docs/keys.md), [docs/COMMANDS.md](docs/COMMANDS.md)).
- **Операции.** Копирование и перенос с очередью и job-баром, вопросы о конфликтах строкой без модальных окон, журнал прерванных операций («Продолжить» после выхода), докачка крупных файлов на сеть и USB, клон блоков ReFS / Dev Drive, быстрая Корзина, удаление, создание папок (в т. ч. дерева), переименование и групповое переименование, ссылки, атрибуты и время, сравнение и синхронизация папок.
- **Терминал.** Встроенный терминал на ConPTY за панелями (Ctrl+O); командная строка с правкой, undo, вставкой имён из панели; интеграция PowerShell, cmd, Git Bash и WSL (bash / zsh / fish): промпт shell в командной строке, каталог панели и shell синхронны в обе стороны.
- **Оформление.** Темы светлая / тёмная / по системе и свои, акцент Windows, настройки во вкладке (F9 → «Настройки»), интерфейс EN и RU.
- **Бюджеты** (меряются на стенде в release): первый кадр < 250 мс, кадр ≤ 2 мс на 100 000 строк, 0 % CPU в простое, бинарь ≤ 30 МБ.

## Вехи

| Веха | Что | Статус |
|---|---|---|
| M0 | Каркас: workspace, окно, bus, CI | ✅ |
| M1 | Навигация: панели, табы, листинг, хоткеи | ✅ |
| M2 | Файловые операции | ✅ |
| M3 | Терминал и командная строка | ⏳ осталось: выделение и прокрутка вывода (S6-07), история и Alt+F8, автодополнение, Enter по файлу (S6-16…S6-22), поставка ConPTY (S6-02) |
| M4 | Вьювер и редактор (S7) | — |
| M5 | Поиск, архивы, сеть (S8) | — |
| M6 | Выпуск: perf, установка (winget, Scoop, MSIX) (S9) | — |
| F-01…F-03 | Анализ места, менеджеры пакетов, SSH | после M3, [docs/01-ROADMAP.md](docs/01-ROADMAP.md) |

Задачи по вехам — `docs/TASKS-M*.md`, ручные проверки и их итоги — [docs/manual-tests/](docs/manual-tests/) (файл на задачу; до 2026-10-24 — ARCHIVE.md).

## Сборка и запуск

Нужен Rust из `rust-toolchain.toml` (rustup подтянет его сам) и MSVC Build Tools.

```bash
cargo build --workspace
cargo clippy --workspace --all-targets -- -D warnings
cargo nextest run --workspace
cargo run -p urfin-app
```

- **Переносной режим:** файл `urfin.portable` рядом с `urfin.exe` — настройки и состояние в `data\` рядом, профиль пользователя не трогается.
- **Снимки экранов без человека:** `urfin.exe --screens <каталог>` — сцены демо-дерева в PNG ([docs/screens](docs/screens)).
- **Замер:** `urfin.exe --bench [каталог]` — кадры, CPU, память, размер ([docs/perf](docs/perf)).
