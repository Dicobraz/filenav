# macOS: накопленные проблемы

macOS в пассиве (S0-decisions): на него не тратим время, CI-джоб `test (macos-latest)` неблокирующий. Здесь собирается всё, что всплыло по macOS, — чтобы при реактивации проблематика была ясна. Пополнять при каждом новом случае: дата, где всплыло, что известно, что сделано.

## Таймеры и планировщик раннера

- **2026-10-15, S1-05/S1-08 (#11, #12).** Отменённый `MsgSink::send` на полном канале разблокировался через 71,7 мс при приёмке ≤60 мс: шаг проверки отмены был 40 мс, задержка планировщика на раннере — до ~30 мс. Шаг уменьшен до 15 мс (платформа-независимо), проблема снята.
- **2026-10-15, S1-11 (#15).** `thread::sleep(9 мс)` на раннере спит около 30 мс (грубый таймер / коалесцирование таймеров macOS): серия из 100 «навигаций по 10 мс» растянулась до 3,3 с. Тест переведён на расписание «старт + i·10 мс». **Правило для тестов:** не полагаться на точность `sleep`, считать от расписания и проверять сами инварианты (паузы, порядок), а не длительность.

## Сборка и инструменты

- **2026-10-15, S1-07 (#9).** Кросс-`cargo clippy --target aarch64-apple-darwin --all-targets` с Windows не собирается: criterion тянет `alloca` с C-кодом, нужен C-тулчейн цели. Локальная кросс-проверка под macOS снята со стенда; macOS проверяет только CI.

## Не проверено на реальном Mac (только компилируется / тесты CI)

- **Пути** (`Paths`, S1-10): `~/Library/Application Support/FileNav` (config, state, logs), кэш — `~/Library/Caches/FileNav`. Ветка кода проверена только тестом CI с подменёнными каталогами.
- **Регистр в масках** (`Mask`, S1-03): на macOS — без учёта регистра (как дефолтный APFS). Регистрозависимые тома APFS не учтены.
- **Unicode-нормализация имён**: HFS+ хранит имена в NFD, APFS сохраняет как есть, но сравнивает с нормализацией. Сравнение имён в core (`pending_focus`, восстановление выделения по именам, `panel.cursor.to`) — побайтовое; имя из ввода в NFC может не совпасть с именем из ФС в NFD. При реактивации — решить на уровне S4 (нормализация при листинге) или сравнения в core.
- **eframe**: в workspace фичи `x11`/`wayland`; меню macOS и `app::sys` (S1-13, S3) не реализованы — по S0-decisions это конец очереди.
