# S0 — решения владельца (ADR-0005)

Статус: 2026-10-14. Имеет приоритет над разделами «Решения для владельца» и мокапами в specs/S1–S9.

## Платформы (обновлено)
- **Windows — единственная активная платформа.** macOS — **в пассиве**: код остаётся кроссплатформенным (cfg-модули, CI собирает и тестирует macOS), но ручная приёмка, Mac-специфичные фичи и релиз macOS не планируются до реактивации владельцем. Linux — tier 2 без изменений.
- **Стенд разработки — Windows 11 владельца, нативно** (обновлено 2026-10-15, заменяет ВМ Debian 13), на нём работает Claude Code (см. HANDOFF-stand-windows.md). Проверка: L0 на стенде (MSVC-сборка, clippy, тесты) → L1 CI windows/ubuntu/macos → L2 ручная приёмка владельцем GUI (`win-manual`). Перф-бюджеты — только Windows. Linux — CI и при необходимости WSL2. Alpine — не стенд (musl), допустим только как headless Docker-образ.

## Принцип дизайна
- **DN/Far — источник функций и раскладки** (две панели, табы, cmdline, keybar F1–F10, F-клавиши), **не визуальный канон.**
- Визуальный язык — **Windows Fluent, ориентир WinUI Gallery (3.0)**. Вариант **A «Explorer-native» с правками**: без командной панели; строка F-клавиш обязательна; табы в заголовке окна (по набору на панель); breadcrumb-путь; иконки; строки 24 px; размеры КБ/МБ/ГБ, цифры tabular; акцент системы; светлая/тёмная по ОС.
- Шрифты: Segoe UI Variable + Segoe Fluent Icons из системы; вшиты JetBrains Mono (терминал/hex) и подмножество Fluent System Icons (MIT) для Win10/прочих ОС.
- Темы DN/Far — не по умолчанию, позже опцией. Превью/миниатюры — не делаем.

## Изменения задач
- **S1-15 Single-instance.** app/`ipc`: Windows — mutex + named pipe `\\.\pipe\filenav-<sid>`; mac/Linux — unix socket + `flock`. JSON `{argv,cwd}` → `tab.new`+`panel.go`, активация окна. Приёмка: <100 мс, stale lock чистится. Зависит: S1-07, S1-13.
- **S1-10:** `General.language` = BCP-47.
- **S2:** стили строк по №31, раскраска по №32.
- **S6:** история — persist/session-only по №30.
- **S9:** релиз M6 — только Windows (MSI, portable zip, winget); macOS-задачи (.dmg, notarization, universal2) — в бэклог «macOS реактивация». CI-джоб macOS остаётся (сборка + тесты).
- **Все сессии:** Mac-специфичные задачи (getattrlistbulk, FSEvents, clonefile, AppKit-меню и т.п.) — после Windows/Linux-аналогов, в конце очереди; cfg-заглушки обязательны, чтобы CI macOS был зелёным.
