# S0 — изменения контрактов v4 (ADR-0007)

Статус: принято S0, 2026-10-14. Источник: specs/S2.md v2 (Fluent) §11 и требование владельца по хоткеям. Дополняет v2/v3.

| # | Изменение |
|---|---|
| 1 | `unsafe` разрешён в `filenav-ui::sys` (Mica/DWM, свой заголовок с табами, чтение темы/акцента ОС). Зависимости: `windows-sys` (ui), `objc2`/`objc2-app-kit` (ui, macOS). Правило «unsafe только в sys» сохраняется |
| 2 | IME включён в Cmdline, Terminal и оверлеях с вводом текста (rename, ввод пути, quick search, черновики операций). Уточняет v3 №13 |
| 3 | Ресурсы: вшиты JetBrains Mono (OFL; терминал/hex/cmdline) и подмножество Fluent System Icons (MIT) для macOS/Linux/Win10. Segoe UI Variable и Segoe Fluent Icons — только с диска ОС |
| 4 | v3 №12 закрыт: моно-шрифт — JetBrains Mono |
| 5 | **Хоткеи с буквой срабатывают на любой раскладке и языке ввода (требование владельца, обязательное).** Правило резолва клавиши для биндинга с латинской буквой/цифрой/символом: (1) если текущая раскладка даёт на этой клавише латинский символ — сравниваем по нему (Dvorak, AZERTY, QWERTZ работают «по надписи»); (2) иначе (кириллица, греческий, иврит, арабский, CJK, IME в любом состоянии) — по физической позиции US-QWERTY (scancode/`egui::Key` physical). Модификаторы Ctrl/Alt/Shift/Cmd не влияют на правило. Применяется ко всем контекстам и аккордам. Исключение: быстрый поиск (Alt+буква / набор в панели) и ввод в cmdline используют набранный символ (`Text`), а не биндинг; при совпадении с биндингом приоритет у биндинга. Опция `keymap.match = "auto" \| "physical" \| "logical"` (по умолчанию auto). Приёмка S3: матрица раскладок en-US, ru, uk, el, he, ar, ja (IME вкл/выкл), zh-Pinyin, ko, Dvorak, AZERTY, QWERTZ — Ctrl+C/V/A/Q/U/O/R, Alt+F7, Ctrl+[ ], Alt+буква дают одну и ту же команду; автотест на синтетических событиях + ручной чек-лист на Windows |
