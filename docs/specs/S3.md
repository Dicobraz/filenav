## 0. Ключевые решения

- **Решение:** сочетание матчится по полю `key` из `egui::Event::Key`. В egui-winit это `logical.or(physical)`. Опция `[keymap] match = "physical"` переключает на `physical_key.or(key)`.
  **Почему:** в русской раскладке логическая клавиша «ф» не распознаётся как `egui::Key`, и egui подставляет физическую `A`. Поэтому `Ctrl+A`, `Alt+F7`, `Ctrl+[` работают без настройки. В латинских раскладках (AZERTY, Dvorak) работает надпись на клавише, как у Far с его VK-кодами. Режим `physical` нужен тем, кто хочет позиции QWERTY.
- **Решение:** клавиатура целиком обрабатывается в `eframe::App::raw_input_hook`. Обработанные события (`Key`, `Text` той же клавиши, `Copy/Cut/Paste`) удаляются из `RawInput`, а команды сразу уходят в `Core::dispatch`.
  **Почему:** виджеты egui не реагируют повторно (Tab двигал бы фокус, Esc закрывал бы что-то ещё, `Text` печатался бы). Отклик укладывается в тот же кадр. Обработка — чистая функция над `RawInput` и `&AppState`, её легко тестировать без окна.
- **Решение:** на Windows ставится неперехватывающий хук сообщений `KeyNotes` через `eframe::NativeOptions::event_loop_builder` и `EventLoopBuilderExtWindows::with_msg_hook`. Он записывает `VK_INSERT/VK_DELETE/VK_ADD/VK_SUBTRACT/VK_MULTIPLY/VK_DIVIDE/VK_CLEAR(Num5)/VK_RETURN(ext)` вместе с модификаторами.
  **Почему:** egui-winit превращает `Ctrl+Ins`, `Shift+Ins`, `Shift+Del`, `Ctrl+C/X/V` в события `Copy/Cut/Paste` без `Key`. Он же отбрасывает `location`: `Gray-` неотличим от `-`, а для `Gray*` нет даже `Key`. Без хука большая часть клавиш Far/DN на Windows не работает.
- **Решение:** печатный текст при фокусе на панели уходит в `cmdline.insert`, как в Far и DN. Быстрый поиск включается так: в Far — `Alt+буква`, в DN — одиночное нажатие Alt (опция). Символ берётся из `Event::Text` (с учётом раскладки), а не из `Key`.
  **Почему:** так ведут себя оригиналы. Для `Alt+ф` Windows шлёт `WM_SYSCHAR 'ф'`, egui превращает его в `Text("ф")`, и поиск находит русские имена.
- **Решение:** keymap собирается из слоёв `base → пресет (far|dn) → os-оверлей → пользовательский файл`. Конфликты разрешает специфичность `when`: больше условий — сильнее. При равенстве побеждает поздний слой. `false` снимает привязку.
  **Почему:** привязку можно переопределить точечно, не копируя пресет. Решение детерминированное и объяснимое (`keymap.show` показывает, из какого слоя пришла привязка).
- **Решение:** автоповтор срабатывает, только если у всех команд привязки `CommandMeta::repeatable` (можно переопределить `_repeat`). Остальные повторы поглощаются.
  **Почему:** зажатая F5 не должна запускать 30 копирований, а курсор, Insert и прокрутка должны повторяться.
- **Решение:** на macOS Ctrl-сочетания Far и DN остаются на Ctrl. Cmd получает только стандартные действия macOS и Finder. Стандартное меню winit выключено (`with_default_menu(false)`), `OptionAsAlt::OnlyLeft`.
  **Почему:** Ctrl на Mac почти свободен, и мышечная память пользователя Far сохраняется. Стандартный пункт Quit (Cmd+Q) в winit вызывает `terminate:` в обход `Handler::on_quit` (вето при активных job). С левым Option как Alt `Option+буква` даёт обычную букву, а не «å», поэтому работают быстрый поиск и Alt-сочетания. Правый Option остаётся для набора спецсимволов.
- **Решение:** в пресетах нет `Ctrl+Alt+<печатная клавиша>` и сочетаний с Win/Super. Привязка к системно-зарезервированным сочетаниям даёт предупреждение.
  **Почему:** на Windows AltGr = Ctrl+Alt (немецкая, польская и другие раскладки), такое сочетание перехватит набор символа. Win- и Cmd-системные сочетания до приложения не доходят.
- **Решение:** `urfin-keymap` зависит от `egui` (`default-features=false`, только типы ввода) и от core. Платформенный код (хук Windows, меню и Option на macOS) живёт в `app::sys`, keymap получает только данные.
  **Почему:** keymap остаётся без `unsafe` и тестируется на Linux CI. Правило ADR-0 «unsafe только в sys» выполняется.
- **Решение:** клавиши серой клавиатуры на macOS и Linux привязаны только к `Gray+` (у него отличается `physical_key`: `Plus` против `Equals`). Для `Gray-`, `Gray*`, `Gray/` есть альтернативы в оверлеях, а upstream-PR в egui-winit (numpad-клавиши) — запрос к S0 №7.
  **Почему:** до правки egui эти клавиши физически неотличимы.

## 1. Ввод: конвейер и ограничения egui/winit

```
winit ─► [Windows: KeyNotes hook] ─► egui-winit ─► RawInput ─► App::raw_input_hook
                     │ notes (VK, mods)                          │
                     └──────────────► KeyInput::process(raw, &AppState) ─► Core::dispatch(Command{origin: Key})
                                         │ удаляет поглощённые события
                                         └─► остаток RawInput ─► egui (виджеты S2/S6/S7)
```

### 1.1 Что даёт egui 0.36 / winit 0.30.13 (по коду) и что мы делаем

### 1.2 Алгоритм `KeyInput::process` (на кадр)

1. Забрать записки `KeyNotes` (Windows) в FIFO.
2. Для каждого события `RawInput.events` по порядку:
   - `Ime(Preedit ≠ "")` → `ime_composing = true`; `Commit`/`Disabled` → false. Пока true — пропускать всё.
   - `Key{pressed}`: обновить `ModTracker`. Если это модификатор — обработать одиночный Alt (§1.4) и пропустить.
   - Собрать `Stroke { key: KeyCode, mods: Mods }`:
     - `KeyCode` берётся из `key` (или `physical` при `match = "physical"`).
     - Затем уточняется запиской: `Minus` + `VK_SUBTRACT` → `GrayMinus`, и т. п.
     - `GrayPlus` определяется по `physical_key == Plus`.
   - `Copy/Cut/Paste` → stroke из записки (Windows) или `Ctrl/Cmd+C/X/V`. Для `Paste` текст сохраняется в аргумент `text` (S6 `cmdline.paste`).
   - `Text(t)`:
     - если стоит `suppress_text`, событие удаляется;
     - иначе, если активен быстрый поиск, → `keymap.qs.input {text}`;
     - иначе, если `focus == Panel` и включён режим Far `Alt+буква` при зажатом Alt, → `keymap.qs.start {text}`;
     - иначе, если `focus == Panel`, → `cmdline.insert {text}`;
     - иначе событие пропускается (виджет).
   - Lookup (§2.5):
     - `Hit` → удалить событие, `suppress_text = true` до следующего `Key`, dispatch;
     - `Prefix` → удалить, `pending = (trie, deadline)`, `UiEvent::Ext{keymap.pending}`;
     - `Miss` при `pending` → сброс аккорда, событие удаляется;
     - `Miss` при активном быстром поиске → `keymap.qs.cancel`, затем повторный lookup (Far: навигационная клавиша закрывает поиск и выполняется).
3. Записка без пары → синтетический stroke и lookup. Если поиск промахнулся и `focus` текстовый, вставить `Event::Text` для `GrayStar/GrayMinus/GrayPlus/GraySlash` (печать `*-+/` в cmdline).
4. Дедлайн аккорда истёк → сброс, `waker.wake_after` до дедлайна.

### 1.3 Быстрый поиск (fast find)

- Режимы `[keymap] quick_search`:
  - `alt` (Far): `Alt+символ`/`Alt+Shift+символ` при фокусе на панели;
  - `alt_tap` (DN «Single Alt»): нажать и отпустить Alt без других клавиш за ≤`alt_tap_ms` (400), затем печатать;
  - `ctrl_tap`: то же с Ctrl;
  - `off`;
  - `auto`: режим берётся из пресета (far → `alt`, dn → `alt_tap`).
- Состояние `QuickSearch { side, mask: String }` хранится в `AppState.ext` (контракт v2 №10) и меняется только handler'ом `keymap`. S2 рисует строку поиска.
- Маска:
  - вводимые символы + неявная `*` в конце; поддерживаются `*`, `?` (Far, DN);
  - `>txt` — «расширение начинается с txt» (DN);
  - сравнение регистронезависимое, по правилам `Mask` из core.
- Клавиши внутри поиска (контекст `qs`):
  - `Ctrl+Enter` / `Down` — следующее совпадение;
  - `Ctrl+Shift+Enter` / `Up` — предыдущее;
  - `Backspace` — удалить символ;
  - `Esc` — выход;
  - `Enter` — выход + `panel.enter`;
  - любая другая привязанная клавиша — выход + её команда;
  - вставка из буфера (`Paste`) добавляет текст, пока есть совпадения (Far).
- Нет совпадения → символ не принимается, курсор не двигается (Far). Курсором двигает `panel.cursor.match` (запрос №2).

### 1.4 Одиночный Alt/Ctrl

`AltLeft|AltRight` нажат, затем отпущен. Между этим не было других `Key`, кнопок мыши или прокрутки, длительность ≤ `alt_tap_ms`, Shift не участвовал (Alt+Shift переключает раскладку в Windows). Тогда срабатывает виртуальный stroke `AltTap` (`CtrlTap`), который можно привязать как обычную клавишу. В DN это `keymap.qs.start`.

## 2. Формат keymap (TOML)

### 2.1 Секция `[keymap]` в `config.toml`

```toml
[keymap]
preset = "far"               # far | dn | <имя файла из config_dir/keymaps/ без .toml>
user = "user.toml"           # пользовательский слой (если файл есть); может содержать extends
match = "auto"               # auto (надпись клавиши) | physical (позиция QWERTY)
quick_search = "auto"        # auto | alt | alt_tap | ctrl_tap | off
alt_tap_ms = 400
chord_timeout_ms = 1500
mac_option_as_alt = "left"   # left | right | both | none
```

### 2.2 Файл keymap (пресет или пользовательский)

```toml
format = 1
name = "my"
extends = "far"              # base | far | dn | <пользовательский>; цепочка ≤4, цикл = ошибка

[context.global]             # ключ секции = when-выражение
"F10" = "ui.menu"
"Alt+X" = "app.quit"

[context.panel]
"Ctrl+R"  = "panel.refresh"                               # id команды
"Ctrl+F5" = { cmd = "panel.sort", key = "mtime" }          # форма S1: {cmd, args…}
"Shift+Down" = ["sel.toggle", "panel.cursor.down"]        # последовательность команд
"Ctrl+K Ctrl+H" = "panel.hidden.toggle"                   # аккорд: до 3 нажатий через пробел
"Up" = { cmd = "panel.cursor.up", _repeat = true }        # _repeat переопределяет CommandMeta
"Ctrl+O" = false                                          # снять унаследованную привязку

[context."panel && cmdline_empty"]
"Ctrl+Left" = { cmd = "ui.split.width", delta = -1 }

[context."*"]                # во всех контекстах
"Ctrl+Q" = false

[os.macos.context.panel]     # оверлей платформы: os.windows | os.macos | os.linux
"Cmd+Up" = "panel.up"
```

Зарезервированные ключи в таблице команды: `cmd`, `_repeat`. Все остальные ключи — аргументы. Проверяются через `CommandRegistry::validate`.

### 2.3 Сочетание (stroke)

- Грамматика: `[Mod+]*Key`, аккорд — strokes через пробел. Регистр не важен. Каноническая форма для показа: `Ctrl+Alt+Shift+Cmd+Key`.
- Модификаторы:
  - `Ctrl`, `Alt` (Option на Mac), `Shift`, `Cmd` (синонимы `Meta`, `Super`; на Windows и Linux не биндится, предупреждение);
  - `Mod` — Ctrl на Windows/Linux и Cmd на macOS;
  - стороны: `LCtrl`, `RCtrl`, `LAlt`, `RAlt` (без стороны — любая).
- Клавиши (имена `egui::Key::from_name` плюс наши):
  - `A..Z`, `0..9`, `F1..F24`;
  - `Enter`, `Esc`, `Tab`, `Space`, `Backspace`, `Insert`, `Delete`, `Home`, `End`, `PageUp`, `PageDown`, `Up`, `Down`, `Left`, `Right`;
  - `Minus`, `Plus`, `Equals`, `[`, `]`, `\`, `;`, `'`, `,`, `.`, `/`, `` ` ``;
  - `GrayPlus`, `GrayMinus`, `GrayStar`, `GraySlash`, `Num5`, `NumEnter`, `AltTap`, `CtrlTap`.

### 2.4 `when`-выражения

- Атомы фокуса (из `AppState.focus`):
  - `panel`, `cmdline`, `prompt`, `viewer`, `terminal`;
  - `editor`, `overlay`, `overlay:<kind>` — после запроса №1;
  - `global` — истинен в `panel|cmdline|viewer|editor`, но не в `terminal|prompt|overlay`. В терминале действуют только явные привязки `terminal`, остальное уходит в PTY.
- Флаги (`FlagRegistry`, их регистрируют крейты):
  - `cmdline_empty` (S6), `qs` (S3), `has_selection` (S1), `on_parent_row` (S1), `in_archive` (S8);
  - `os_windows`, `os_macos`, `os_linux`.
- Операторы: `!`, `&&`, `||`, скобки. `*` — любой контекст (только для снятия привязок).
- Специфичность: `global` = 0, иначе число атомов в сработавшей конъюнкции. Побеждает максимум. При равенстве — более поздний слой (`user > os > preset > base`). Равенство внутри одного файла — предупреждение `Ambiguous`, побеждает последняя строка.

### 2.5 Компиляция, конфликты, предупреждения

- Загрузка:
  - встроенные `base.toml`, `far.toml`, `dn.toml` (include_str) и пользовательские файлы из `config_dir/keymaps/` разбираются в `KeymapFile`;
  - `extends` разворачивается, применяется os-оверлей;
  - получается `Compiled { single: FxHashMap<Stroke, SmallVec<[Entry;2]>>, chords: Trie }`.
- `Entry { when: WhenId, cmds: Arc<[Command]>, layer: u8, spec: u8, repeat: Option<bool>, src: SrcRef }`.
- Предупреждения (`KeymapWarning`, баннер через `ConfigWarning`; ошибка не блокирует старт):
  - неверный ввод: `UnknownCommand`, `BadArgs`, `BadKey`, `BadWhen`, `UnknownFlag`;
  - коллизии: `Ambiguous`, `PrefixShadow` (одиночная привязка совпадает с префиксом аккорда в том же контексте — аккорд побеждает, одиночная отключается);
  - запрещённые сочетания: `Reserved` (список §4, никогда не дойдёт), `AltGrRisk`;
  - структура файлов: `ExtendsCycle`, `Duplicate`.
- Перезагрузка: `keymap.reload` и `app.reload_config`. Новая `Arc<Keymap>` подменяется атомарно, аккорд и быстрый поиск сбрасываются.

## 3. Таблица команд и сочетаний

Обозначения:
- Владелец указан при id, если это не S3: (S1), (S2)…; «запрос» — новая команда или аргумент через S0 (§6).
- «—» — не привязано (команда доступна в палитре и меню).
- Колонка macOS дана для пресета Far: «=» — как в Far (F-клавиши с Fn), через «;» — дополнительные Cmd-сочетания.
- `ce` = `cmdline_empty`.
- Контекст по умолчанию — `panel`, иначе указан.
- Повтор (R) отмечен у repeatable-команд.

### 3.1 Панели: навигация и вид

| CommandId | Описание | DN | Far | macOS |
|---|---|---|---|---|

## 4. Системные сочетания: не перехватываем

Keymap помечает их `Reserved`. Привязка допускается, но выдаёт предупреждение «не дойдёт».

| ОС | Сочетание | Что делает ОС | Альтернатива в Urfin |
|---|---|---|---|
| Win 11 | Win+любое | оболочка (Win+E/R/D/L/V/./Space/стрелки…) | Super не используется |
| Win | Alt+Tab, Alt+Shift+Tab, Alt+Esc, Ctrl+Esc | переключение окон, Пуск | — |
| Win | Ctrl+Shift+Esc, Ctrl+Alt+Del | диспетчер задач, SAS | — |
| Win | Alt+F4 | закрыть окно (winit не доставляет) | закрытие идёт через `app.quit` с вето; альт. редактор → Alt+Shift+F4 |

## 5. API крейта `urfin-keymap`

```rust
// ---- типы ----
#[derive(Copy, Clone, Eq, PartialEq, Hash, Debug)]
pub enum KeyCode { Key(egui::Key), GrayPlus, GrayMinus, GrayStar, GraySlash, Num5, NumEnter, AltTap, CtrlTap }
bitflags::bitflags! { pub struct Mods: u16 { const CTRL=1; const ALT=2; const SHIFT=4; const CMD=8;
    const LCTRL=16; const RCTRL=32; const LALT=64; const RALT=128; } }   // сторона — только если указана в биндинге
#[derive(Copy, Clone, Eq, PartialEq, Hash, Debug)] pub struct Stroke { pub key: KeyCode, pub mods: Mods }
pub struct Chord(pub SmallVec<[Stroke; 3]>);
impl Stroke { pub fn parse(s: &str, os: Os) -> Result<Self, KeyError>; pub fn display(&self, os: Os) -> CompactString; }
impl Chord  { pub fn parse(s: &str, os: Os) -> Result<Self, KeyError>; }
#[derive(Copy, Clone, Eq, PartialEq, Debug)] pub enum Os { Windows, Macos, Linux }

// ---- when ----
pub struct When(/* AST */);
impl When { pub fn parse(s: &str, flags: &FlagRegistry) -> Result<Self, WhenError>; pub fn specificity(&self) -> u8; }
pub type FlagFn = fn(&AppState) -> bool;
pub struct FlagRegistry { /* FxHashMap<&'static str, FlagFn> */ }
impl FlagRegistry { pub fn with_builtin() -> Self; pub fn register(&mut self, name: &'static str, f: FlagFn); }

// ---- keymap ----
#[derive(Clone, Debug, Serialize, Deserialize)] #[serde(default)]
pub struct KeymapCfg { pub preset: CompactString, pub user: Option<String>, pub r#match: MatchMode,
    pub quick_search: QsMode, pub alt_tap_ms: u16, pub chord_timeout_ms: u16, pub mac_option_as_alt: OptionAlt }
pub struct Keymap { /* Compiled, os, warnings */ }
pub enum Lookup<'a> { Hit(&'a [Command], bool /*repeat ok*/), Prefix, Miss }
impl Keymap {
    /// Не падает: ошибки → предупреждения. Встроенные пресеты + config_dir/keymaps/.
    pub fn load(paths: &Paths, cfg: &KeymapCfg, reg: &CommandRegistry, flags: &FlagRegistry, os: Os)
        -> (Arc<Keymap>, Vec<KeymapWarning>);
    pub fn from_str_layers(layers: &[(&str, Layer)], reg: &CommandRegistry, flags: &FlagRegistry, os: Os)
        -> (Arc<Keymap>, Vec<KeymapWarning>);           // для тестов
    pub fn lookup(&self, pending: Option<&ChordState>, s: Stroke, st: &AppState) -> Lookup<'_>;
    pub fn keys_for(&self, cmd: &Command, st: &AppState) -> SmallVec<[Chord; 2]>;   // меню/палитра S2
    pub fn keybar(&self, mods: Mods, st: &AppState) -> [Option<KeybarItem>; 12];  // F1..F12, S2
    pub fn effective(&self) -> impl Iterator<Item = EffectiveBinding<'_>>;        // keymap.show/dump
    pub fn warnings(&self) -> &[KeymapWarning];
}
pub struct KeybarItem { pub cmd: CommandId, pub label_key: CompactString /* Fluent "keybar-<id>" */ }

// ---- ввод ----
/// Clone + Send. Пишет хук Windows, читает KeyInput.
#[derive(Clone, Default)] pub struct KeyNotes(Arc<Mutex<VecDeque<KeyNote>>>);
#[derive(Copy, Clone, Debug)] pub struct KeyNote { pub vk: u16, pub extended: bool, pub mods: Mods, pub down: bool }
impl KeyNotes { pub fn push(&self, n: KeyNote); }

pub struct KeyInput { /* keymap, ModTracker, ChordState, AltTap, ime, suppress_text, notes */ }
impl KeyInput {
    pub fn new(km: Arc<Keymap>, cfg: &KeymapCfg) -> Self;
    pub fn notes(&self) -> KeyNotes;
    pub fn set_keymap(&mut self, km: Arc<Keymap>);
    /// Вызывается в App::raw_input_hook. Удаляет поглощённые события, команды — в out (Origin::Key).
    pub fn process(&mut self, raw: &mut egui::RawInput, st: &AppState, now: Instant, out: &mut Vec<Command>) -> InputOutcome;
}
pub struct InputOutcome { pub wake_at: Option<Instant> }   // дедлайн аккорда / alt-tap

// ---- handler "keymap" ----
pub fn register(core: &mut Core, cfg: KeymapCfg, flags: FlagRegistry) -> KeyInput;
// команды: keymap.reload, keymap.preset{name}, keymap.show, keymap.dump{path?}, keymap.qs.{start,input,next,prev,backspace,cancel}
// ext-состояние: KeymapView { qs: Option<QuickSearch>, pending: Option<CompactString>, warnings: usize }
```

Платформенный код в `urfin-app`:
- `app::sys::windows::install_key_notes(builder: &mut EventLoopBuilder<UserEvent>, notes: KeyNotes)`. Внутри `with_msg_hook`, возвращает всегда `false` (не поглощает).
- `app::sys::macos::configure(builder)` (`with_default_menu(false)`) и `configure_window(&winit::window::Window, OptionAlt)` (`set_option_as_alt`), `hide_app()` (`NSApplication::hide`). Плюс обработчики `ui.window.hide`.

Бюджеты:
- `lookup` <300 нс;
- `process` <20 мкс на кадр с ≤10 событиями;
- загрузка трёх слоёв <2 мс;
- 0 аллокаций в `lookup`.

## 8. Решения для владельца

1. **Пресет по умолчанию.** Определяет, что увидит пользователь при первом запуске.
   - Варианты:
     - (а) Far — Alt+буква = поиск, F10 = выход, F9 = меню;

2. **F10.**
   - Варианты:
     - (а) как в оригиналах: Far — выход, DN — меню;
     - (б) везде меню, выход только Alt+X / Cmd+Q;
     - (в) (а) + inline-подтверждение выхода одной строкой (`confirm_quit = true`, Enter/Esc), вето при активных задачах в любом случае.
   - Рекомендация: **(в)**.
3. **Cmd на macOS.**
   - Варианты:
     - (а) Cmd заменяет Ctrl во всех привязках;
     - (б) Ctrl остаётся как в Far/DN, Cmd — только стандарты macOS/Finder (Cmd+C/V/Q/W/T/F/Up/Down/Backspace/[ ]…);
     - (в) оба: каждое Ctrl-сочетание дублируется на Cmd.

   - Варианты:
     - (а) оставить семантику Far/DN, табы на Ctrl+Tab / Ctrl+Shift+Tab, Ctrl+Shift+T/W (Far) и Ctrl+F3/F4 (DN);
     - (б) отдать Ctrl+PgUp/PgDn табам, «вверх» = Backspace (при пустой cmdline) и Ctrl+\.
   - Рекомендация: **(а)**.
5. **Печать при фокусе на панели.**
   - Варианты:
     - (а) в командную строку (Far/DN), поиск — Alt / одиночный Alt;
     - (б) сразу быстрый поиск (Explorer/TC), командная строка — по Ctrl+E или клику.
   - Рекомендация: **(а)** в обоих пресетах. (б) можно включить в пользовательском keymap (`quick_search = "typing"` — фаза 2).
