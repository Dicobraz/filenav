# Приведение интерфейса к дизайну (D)

GPUI-интерфейс уже есть (G-02…G-07, #88), дизайн утверждён позже (S0-decisions №59–№62, `docs/design/DESIGN.md`). Задачи D — довести текущие экраны до снимков `docs/design/screens/`. Колонка «Задача» в DESIGN.md (G-04, G-05, S6, S7) указывает область кода; выполнять — по этому пакету.

Порядок — как ниже. Ветка `d/NN-кратко`, PR на задачу, метка `win-manual`. Приёмка каждой задачи: снимки `urfin --screens` (#102) нужных сцен рядом со снимками дизайна в PR; расхождения — только оговорённые в PR (шрифт на снимках дизайна — заменитель Segoe UI). Недостающие сцены в `--screens` добавлять в той же задаче.

## D-01 Темы (T-01)
`docs/TASKS-THEMES.md` целиком: роли, 6 тем, «как в ОС», высокая контрастность, политики, индикатор администратора/удалённой сессии, тест на литералы цвета. Без Mica (№60): если Mica включается где-то в `ui::sys` — убрать вместе с настройкой `backdrop`.

## D-02 Каркас окна
Наборы табов по панелям (граница по сплиттеру, свой «+», активный таб неактивной панели — `secondary` без крестика; в терминале табов нет, у скрытой панели — нет её набора); иконочный таб панелей в F3/F4/настройках; заголовок панели (путь, подчёркивание `accent` у активной); статус-строка в три зоны и правило №61; keybar (10 клавиш — по ширине, меньше — слева); зона событий внизу (№63): тосты — справа снизу над ней, баннеры — строкой над job-баром, по одному с «ещё N». Сцены: `theme-*`, `context-admin`.

## D-03 Панели и режимы
Строки 20/24/28, курсор и отметка, раскраска типов, иконки (нет/моно/цвет); Brief, дерево, сведения, быстрый просмотр; диски (корешок у края), архив как папка, состояния «пусто / нет доступа / нет связи». Сцены: `density-20-color-icons`, `screen-brief`, `-tree`, `-info`, `-quickview`, `-drives`, `-archive`, `-errors`.

## D-04 Встроенные строки
F5, F8, конфликт, отметка группы, быстрый поиск: накрывают нижнюю часть панелей, курсор не прячется (прокрутка); клавиши — на кнопках, keybar показывает только дополнительные. Сцены: `screen-copy`, `-delete`, `-conflict`, `-select`, `-quick`.

## D-05 Меню
F9 — «мешочек» (корешок в любом месте верхнего края списка, вогнутые скругления 8; у края — прямой угол); контекстное меню — плашка без корешка; то же правило для всех выпадающих полей. Сцены: `screen-menu`, `-context`.

## D-06 Job-бар и терминал
Job-бар занимает место над командной строкой (строка 30, прогресс 4, «ждёт ответа» — `context_remote`); терминал под панелями (Ctrl+O, Ctrl+F1/F2) по `screen-terminal`, `-termhalf` — в рамках S6, если отрисовка терминала ещё не готова.

## D-07 Поиск, просмотр, редактор
Alt+F7 (поля, результаты с подсветкой, предпросмотр), F3 (шапка, переключатель режимов, полоса прокрутки с метками), F4 (поля: изменения/номера/свёртка, мини-карта, строка поиска). По готовности соответствующих частей (search, S7). Сцены: `screen-search`, `-viewer`, `-editor`.

## D-08 Настройки
Вкладка настроек: «Вид» (карточки тем, высота строки, иконки), «Панели», «Клавиатура» (пресет, захват сочетания, конфликты), «Редактор»; применяется сразу. Сцены: `screen-settings*`.
