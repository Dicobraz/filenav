# Дизайн Урфина — передача в разработку

Утверждён владельцем 2026-10-20 (S0-decisions №59–№62). Источник — холст «Урфин — темы оформления» (Claude Design); его исходник окна — `window.dc.html` (HTML/CSS: точные отступы, размеры, цвета ролей), снимки — `screens/*.png` (1280×760, 100 %). Пересобрать снимки после правки исходника: `python scripts/design/render_screens.py docs/design/window.dc.html docs/design/screens` (Playwright + Chromium). Палитры и роли — `docs/THEMES.md`. Расхождение кода с этим документом решается в пользу документа, кроме противоречий с S0-decisions.

Интерфейс на GPUI уже сделан (#88); приведение к этому дизайну — пакет `docs/TASKS-DESIGN.md` (D-01…D-08), колонка «Задача» ниже — область кода.

Снимки — образец раскладки, пропорций и цвета, не попиксельный эталон: шрифт на снимках — заменитель Segoe UI (рендер не на Windows).

## Общие правила
- **Верх — навигация, низ — события** (№63). Тост — только пассивное сообщение без кнопок; всё, где есть действия, — встроенная строка (как F5): на ширину активной панели, если касается её, или на всю ширину, если обеих. Сверху только табы и пути. Всё событийное — внизу, снизу вверх: keybar → статус → командная строка → job-бар → строка-вопрос/баннер; тосты — справа снизу над этой зоной (отступ 12 от её верхнего края, стопка ≤3 вверх).
- Без модальных окон: всё, что спрашивает, — **встроенная строка внизу**, она **накрывает** нижнюю часть панелей (список не перестраивается; если курсор оказался под строкой — список прокручивается так, чтобы курсор был виден). Исключение — job-бар: живёт долго, поэтому **занимает место** над командной строкой и сдвигает панели.
- **Одна информация — одно место** (№61): имя файла — во вкладке; путь — в заголовке экрана/панели; размер, кодировка, переводы строк, тип — в статус-строке; переключатели режимов — в заголовке экрана; клавиши встроенной строки — подписями на её кнопках и **не** повторяются в keybar (keybar в это время показывает только дополнительные клавиши: Tab, F3 и т. п.).
- **Всплывающий список и его кнопка — одна фигура** («мешочек»): меню F9, выпадающие поля, кнопки со списком. Открытая кнопка становится корешком цвета `panel` без нижней границы и перетекает в список; корешок — в любом месте верхнего края списка, как удобнее для компоновки (подробно — `screen-menu.png`). Контекстное меню без кнопки-якоря — обычная плашка.
- **Издатель**: в технических идентификаторах — `Aahz` (CompanyName exe, `HKLM\Software\Policies\Aahz\Urfin`, id пакета winget); имя «Антон Антропов» — только в текстах для человека («О программе», `LegalCopyright` exe — добавить в D-08).
- Цвет — только роли темы; литералы запрещены (T-01-6). Акцент — только для фокуса/курсора/основной кнопки; красный (`modified`) — для опасного действия; `context_remote` (янтарь) — для «ждёт ответа».
- **Строки с вопросом**: предупреждение (баннер журнала, конфликт) — весь фон `warning_bg` + черта `context_remote`; опасное действие (F8) — фон `danger_bg` + черта `modified`; обычные (F5, отметка, переименование, сравнение) — фон `header` + черта `accent`. **Кнопки — сразу за текстом/полями**, не прижаты к правому краю: мышь не ходит через всю ширину.
- Шрифты: интерфейс Segoe UI Variable 13 px; моно Cascadia Mono 12,5–13 px; вторичные подписи 12 px; заголовки колонок 11,5 px. Цифры — tabular.
- Иконки — Segoe Fluent Icons, монохром `secondary` (на курсоре — `cursor_text`); цветной режим — по ролям типов.
