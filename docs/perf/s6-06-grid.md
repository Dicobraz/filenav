# S6-06: рендер сетки терминала

Сетка рисуется одним `canvas` (`crates/ui/src/gpui_shell/term_view.rs`) из снапшота экрана
(`urfin_term::vt::grid::Snapshot`, берётся под замком эмулятора). Снапшот пересобирается
только по флагу изменений сеанса; без вывода кадров нет (0 % CPU).

## Замеры (стенд владельца, release, 2026-10-22)

`urfin --bench` (gen-100000-s1, окно 1200×760), фаза `term`: панели спрятаны,
сетка 200×60 плотного цветного текста (слово — свой цвет из 256, каждое пятое
жирное) меняется **каждый кадр**, т. е. полная пересборка, 200 кадров:

| Метрика | p50 | p99 |
|---|---:|---:|
| Снапшот + отрисовка сетки (`term_grid`) | 1,63 мс | 2,47 мс |
| Кадр (`term`, ограничен vsync) | 6,95 мс | 8,13 мс |

Бюджет S6 §2 — полная пересборка ≤ 4 мс на кадр: выполнен с запасом.

`cargo bench -p urfin-term --bench pipeline -- grid` — снапшот 200×60 (`ls --color`-поток):
медиана **0,10 мс**.

Бинарь — 26,36 МиБ (бюджет 30, №80).

## Сцены `--screens`

`term-frames` (рамки mc/Far), `term-unicode` (кириллица, CJK, эмодзи, блоки, рамки,
Powerline), `term-colors` (16/256 цветов, truecolor, начертания) — образцы в
`docs/screens/s6-06`.
