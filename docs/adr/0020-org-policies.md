# ADR-0020: Политики организации

Статус: принято (владелец, 2026-10-21, S0-decisions №66); пересмотрено 2026-10-23 (№86): два источника — файл TOML и реестр (GPO), без привязки к Microsoft как базе.

## Контекст
Администраторам нужно закреплять часть настроек на машинах (тема, удаление в корзину, проверка после записи, функции с повышенным риском). Урфин не ориентируется на экосистему Microsoft как на основу: домен может быть AD, Samba AD, FreeIPA или его может не быть; средства доставки — GPO, Intune, Ansible, Salt, Puppet, SCCM, скрипты. Нужен нейтральный механизм, который Microsoft-инструменты поддерживают, но не определяют.

## Решение
**Политики только машинные.** Пользовательские источники (`HKCU\Software\Policies`, файлы в профиле) не читаются — пользователь не может подменить политику.

**Два читателя, одна модель в памяти:**

| Источник | Где | Чем доставляется |
|---|---|---|
| **TOML** | `%ProgramData%\Urfin\policy.toml` — ACL ставит установщик: запись только Administrators/SYSTEM, чтение всем | любое средство управления конфигурацией, скрипт, MSI-трансформ, вручную |
| **GPO** | `HKLM\Software\Policies\Aahz\Urfin` | AD GPO и Samba AD (по ADMX-шаблону), Intune (ADMX ingestion), `reg import` |

- Оба читаются при старте и заново при изменении: слежение за папкой `%ProgramData%\Urfin` и `RegisterGPNotification` (обновление групповой политики). Значения объединяются в один `PolicySet` **в памяти**; на диск Урфин ничего не пишет.
- Ключ задан в обоих источниках — побеждает **GPO**.
- Отсутствующее значение = «не задано», действует настройка пользователя.
- Заданный политикой параметр в настройках — с замком и недоступен; раздел «Политики» — только чтение, у каждого значения подписан источник: **«TOML»** или **«GPO»**.
- Сеть не используется: только локальный файл и локальный реестр.
- FreeIPA и прочие не-AD — через TOML. Сервер единого входа (Authentik и т. п.) к политикам отношения не имеет (возможная роль — SSH-сертификаты, F-03 v2).

**Ключи** (соответствие один к одному; в реестре — по соглашению Windows CamelCase):

| TOML | Реестр | Тип | Смысл | Статус |
|---|---|---|---|---|
| `theme` | `Theme` | строка / REG_SZ | тема | принято (T-01-5) |
| `theme_locked` | `ThemeLocked` | bool / DWORD | смена темы недоступна | принято (T-01-5) |
| `delete_to_trash` | `DeleteToTrash` | bool / DWORD | F8 всегда в Корзину, безвозвратное (Shift) недоступно | принято (№66) |
| `experimental_fast_trash` | `ExperimentalFastTrash` | bool / DWORD | false — «быстрая корзина» запрещена | принято (№66, №79) |
| `verify` | `Verify` | `none`/`size`/`hash` / REG_SZ | минимальная проверка после записи | принято (№66) |
| `du_elevated_helper` | `DuElevatedHelper` | bool / DWORD | false — досчёт с правами администратора запрещён | предложено (ADR-0021) |
| `du_elevated_mft` | `DuElevatedMft` | bool / DWORD | false — быстрый обход тома (MFT) запрещён | предложено (ADR-0021) |
| `password_cache` | `PasswordCache` | bool / DWORD | false — пароли и фразы-пароли не сохраняются нигде | принято (№89) |
| `ssh.recording` | `SshRecording` | `required`/`forbidden`/`user` / REG_SZ | запись SSH-сеансов | принято (№89) |
| `ssh.multi_exec` | `SshMultiExec` | bool / DWORD | false — мультивыполнение запрещено | принято (№89) |

Пример `policy.toml`:
```toml
# Политика организации для Урфина. Писать — только администратор.
delete_to_trash = true
verify = "size"

[ssh]
recording = "required"
```

## Последствия
- Общий модуль политик (`PolicySet`: читатели TOML и реестра, объединение, уведомления; чтение реестра — в `sys`), потребители — ops, ui, du, ssh. Конфиг пользователя накладывается поверх незаданных значений.
- Установщик (S9): создать `%ProgramData%\Urfin` с ACL «запись — только администраторы».
- S9: ADMX + ADML (ru-RU, en-US) для ключей реестра; пример `policy.toml` с комментариями в дистрибутиве.
- Строки UI — через urfin-i18n.
- Ручная проверка: задать значение в TOML, потом то же в реестре — в «Политиках» источник «GPO»; удалить из реестра — источник «TOML» без перезапуска; пользователь без прав не может изменить файл.
