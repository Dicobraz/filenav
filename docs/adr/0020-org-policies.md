# ADR-0020: Политики организации для операций

Статус: принято (владелец, 2026-10-21, S0-decisions №66)

## Контекст
Сейчас политики организации есть только для темы (`Theme`, `ThemeLocked`, T-01-5). Администраторам нужно также закреплять параметры операций — удаление в корзину и проверку после записи; экспериментальную «быструю корзину» — запрещать.

## Решение
Ключ `HKLM\Software\Policies\Aahz\Urfin` (идентификатор издателя — Aahz, №66 дизайна), читается при старте, только чтение:

| Значение | Тип | Смысл |
|---|---|---|
| `Theme` | REG_SZ | тема (уже есть) |
| `ThemeLocked` | DWORD | 1 — смена темы недоступна (уже есть) |
| `DeleteToTrash` | DWORD | 1 — F8 всегда в Корзину, безвозвратное удаление (Shift) недоступно; 0 — по настройке пользователя |
| `ExperimentalFastTrash` | DWORD | 0 — «быстрая корзина» запрещена |
| `Verify` | REG_SZ | `none` / `size` / `hash` — минимальная проверка после записи |

Отсутствующее значение = «не задано», действует настройка пользователя. Заданный политикой параметр в настройках показан с замком и недоступен; раздел «Политики» — только чтение (`docs/design/screens/screen-settings-policies.png`, `screen-settings-ops.png`).

## Последствия
- `ops` получает `PolicySet` (чтение реестра — в `ops::sys`), конфиг пользователя накладывается поверх.
- Новые строки UI — через urfin-i18n.
- Ручная проверка: задать значения в реестре, проверить замки и поведение F8/Shift+F8.
