# ADR-0014: ввод пути и меню подкаталогов breadcrumb — через handler `ui` и полосу Interactive

Статус: принято (владелец, 2026-10-17, при S2-12).

## Контекст

S2-12 требует от breadcrumb:
- меню подкаталогов по `›`. Список берётся через `Vfs::list` на полосе Interactive, и его можно отменить;
- ввода пути (`ui.path_edit`). Если пути нет, показывается тост, а путь не меняется.

Обоим нужен I/O. Делать его можно только вне UI-потока.

Сейчас для этого нет пути:
- Виджеты (`UrfinUi::show`) видят только `&AppState` и выдают команды. Запустить задачу на `Runtime` они не могут.
- В S2 §3 команды `ui` «без I/O»: `ui.path_edit {side?}` только открывает поле, у `ui.menu {menu?}` — один аргумент.
- `panel.go` переходит сразу. Несуществующий путь даёт таб в состоянии `Failed`, а не тост с прежним путём.

## Решение (предложение)

Handler `ui` (S2) сам I/O не делает. Он ставит задачу на `cx.rt` с полосой Interactive и `CancelToken`, а результат возвращает `Msg` с проверкой поколения. Для этого два аргумента:

1. **`ui.path_edit {side?, path?:Str}`.**
   - Без `path` — как сейчас: открыть поле.
   - С `path` — подтвердить ввод. Относительный путь считается от `Tab.loc` (S1 §7.3). Задача проверяет, что каталог существует (`Vfs::list`, первый чанк или ошибка). Если существует — `panel.go`; если нет — тост `ui-path-not-found`, поле остаётся открытым с тем же текстом.
2. **`ui.menu {menu?, side?, path?:Loc}`.** При `menu = "subdirs"` открывается меню подкаталогов `path` в breadcrumb панели `side`.
   - Задача читает только каталоги, сортирует натурально, ограничивает 500 пунктами.
   - Результат кладётся в `UiState.menu` (`MenuState::Subdirs`).
   - `ui.cancel` и повторный клик отменяют задачу.
   - Пункт меню → `panel.go`.

Другие варианты:
- **Отдельные команды** (`ui.path_submit`, `ui.crumb_menu`). Это то же самое, но пространство `ui` растёт быстрее.
- **Флаг `verify` у `panel.go`.** Меняет контракт core, а нужен он только для ввода пути.
- **Дать UI доступ к `Runtime`.** Меняет контракт `UrfinUi`, и виджеты начинают запускать задачи сами.

## Последствия

- Аргументы обоих — опциональные; старые привязки S3 не меняются.
- `ui-path-not-found` (en+ru) — новый ключ Fluent.
- Для архивов (`>>`) меню и проверка работают, когда появится Vfs архивов (S8). До этого пункты — только для локальных путей.
