# Ручные тесты (L2, Windows)

Сюда собирается всё, что проверяет только владелец руками: окно, ввод, поведение ОС. Каждый PR с меткой `win-manual` добавляет свой раздел. Раздел пройден — PR мёржится; найденное записывается в «Результат» и уходит в фиксы.

**Как проходим.** По готовности владельца собирается одна сборка со всеми ещё не принятыми PR (portable-копия, данные — рядом, профиль не трогается). Разделы идут по порядку; шаг — действие и ожидание. Отметка: ✅ / ❌ + коротко, что не так.

**Сборка.** `%TEMP%\fn-manual\filenav.exe` (+ `filenav.portable`). Сбросить состояние — удалить `%TEMP%\fn-manual\data`.

## 1. Окно, старт, разворот — регрессия S1-13 (принято в #19)

Повторять при изменениях окна и рендера; рендер — wgpu DX12 (ADR-0012).

| № | Действие | Ожидание | Отметка |
|---|---|---|---|
| 1.1 | Запустить (окно было обычным) | Окно появляется один раз, сразу с содержимым панелей: без белого/пустого кадра | |
| 1.2 | Развернуть, закрыть, запустить снова | Открывается развёрнутым, без мигания | |
| 1.3 | Развернуть/восстановить 10–20 раз (двойной клик по заголовку, Win+↑/↓) | Без чёрного кадра, без двоения текста, без подвисания | |
| 1.4 | Входить в каталоги и выходить (Enter / Backspace) | Панель не мигает пустой | |
| 1.5 | Сдвинуть и изменить размер окна, закрыть крестиком, запустить снова | То же место, размер и каталоги | |
| 1.6 | Диспетчер задач, 30 с простоя | CPU 0 %; память — записать | |
