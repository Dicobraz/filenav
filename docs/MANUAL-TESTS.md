# Ручные тесты (L2, Windows)

Сюда собирается всё, что проверяет только владелец руками: окно, ввод, поведение ОС. Каждый PR с меткой `win-manual` добавляет свой раздел и строку в «Статус разделов».

**Порядок (владелец, 2026-10-17).** PR мержатся сразу после зелёного CI. Ручная проверка идёт после мержа по сборке со всеми ещё не проверенными разделами. Что не так — в «Результат» и отдельным fix-PR. Раздел перепроверяется после фикса.

**Как проходим.** Сборка — одна, portable-копия: данные рядом, профиль не трогается. Разделы идут по порядку, шаг — действие и ожидание. Отметка: ✅ или ❌ + коротко, что не так.

**Сборка.** Архив `Urfin-проверка-vN.zip` (последний — v4) или `%TEMP%\fn-manual\urfin.exe` + `urfin.portable`. Сбросить состояние — удалить `data\` рядом с exe.
