Urfin — самопроверка на macOS

1. Распаковать архив артефакта urfin-macos-selftest (из CI) в любую папку.
2. В Терминале:
     cd <папка>
     zsh selftest.sh
3. ~2 минуты не трогать клавиатуру и мышь: окно Urfin само откроется,
   развернётся, уйдёт в полный экран и закроется несколько раз.
4. Прислать файл ~/Desktop/urfin-selftest-<дата>.tgz.

Бинарь universal (Apple Silicon и Intel), без подписи; скрипт сам снимает
карантин с копии. Ничего не ставится, в сеть ничего не уходит, профиль
пользователя не трогается: всё пишется во временную папку /tmp/urfin-selftest.*.
Разрешения системы (запись экрана, универсальный доступ) не нужны: снимки
делает само приложение.
